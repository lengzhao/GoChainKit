# libp2p 与简化 PoW 设计

设计已获用户确认：Go libp2p 网络插件，固定低难度 PoW、累计工作量选链、分叉重组、断线追赶和三节点验证；不实现比特币协议兼容、动态调难、奖励或经济模型。

网络使用持久身份和配置种子节点，独立协议流传输有界消息；握手比较协议描述符与创世。网络只传协议编码字节，接入层处理交易、区块与缺失祖先同步，不能信任远端提供的累计工作量。节点身份不等于挖矿授权或共识权重。

PoW 能力由可选协议实现提供，交易和区块仍保留最小接口。示例协议可复用 KV 交易与执行语义，单独定义含 nonce、目标和父引用的区块；工作量及难度由本地协议验证与计算，固定低难度作为创世绑定的一部分。

Ledger 保留现有线性 Commit，另增分支导入及主链选择能力。每个验证分支保存对应状态、执行结果与父关系；累计工作量由本地已验证记录相加。只有严格更重分支切换主链，同权保留当前链。切换在单次事务中更新链头及确认交易、回执索引；旧分支独有交易重新验证后可回池。

网络接收不得触发任意候选错误导致全节点退出；本地存储损坏和运行资源失败须被监督并报告。超限、坏编码、错误网络身份、无效工作量必须拒绝；缺失祖先按请求补齐，限制批次和深度，断线重连及重启后可追赶。

验收：三节点独立实例竞争出块后停止挖矿能收敛；断网分叉重连后较重链胜出；落后节点及重启节点追赶后链头、状态一致；伪造目标和累计工作量不能骗过本地验证，交易索引与回执跟随重组一致。低难度实现仅用于开发验证。
