# 协议接口重构

状态：接口与实现迁移完成。默认协议及自定义格式的出块、落盘、恢复测试通过；规格审查与代码质量复审通过。

用户已确认将区块、交易及配套规则抽象为可替换协议，并要求贯穿全部接口调整。

实施顺序：定义格式无关契约；将固定格式移至默认 KV 协议；迁移交易池、构块、协调器、执行器和存储；补自定义非 KV 格式的出块、落盘与恢复验证；执行回归与审查。

ID 与 Commitment 采用不可变、不定长二进制字符串；对象只暴露 ID，格式和语义通过 Protocol 注入。ProtocolDescriptor 标识名称、版本和网络，不匹配时拒绝装配或打开数据库。默认 KV 协议保留原签名与规范哈希规则。

存储保存协议编码字节，不持久化 Go 接口实例；磁盘格式升级并拒绝旧格式，不自动迁移或覆盖已有数据库。通用存储保持单一 canonical cursor，多头链可扩展存储能力；协议可验证额外区块引用。

验收：核心与通用插件不依赖默认类型或固定哈希/签名/序号/高度字段；默认链回归通过；自定义协议使用不同字段、ID 长度和承诺算法，通过同一组插件出块、落盘、重开并继续执行。
